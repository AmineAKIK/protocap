# Archived source documents

This directory contains legacy/source Word documents retained for traceability. Binary office files are intentionally kept out of the repository root because they are not diff-friendly and should not be mistaken for executable project assets.

Where the repository contains an HTML/React representation of the same subject, that reviewable version is preferred for code review and portfolio presentation.

These documents are non-software material and are not automatically licensed under the repository's software licence. See `../../LICENSING.md`.
